# Agentic Coding Starter Kit

This repository contains set of skills to boost up the feature planning and
implementation.

## Pipeline

* DESIGN
  * Make a design doc. Example: `design\game.md`.
* PLAN
  * Prompt: `plan this feature design\<feature>.md` or `continue planning this feature design\<feature>.md`
* IMPLEMENTATION
  * Prompt: `start implementing specs\<feature>` or `continue implementing specs\<feature>` or
